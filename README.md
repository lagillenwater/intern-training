# intern-training

Training materials for lab interns. Each task is a self-contained folder under `tasks/` with its own instructions, notebooks, and checks.

## Tasks

- [ESM-2 enzyme transfer](tasks/esm2-enzyme-transfer/README.md): fine-tune a protein language model on human enzymes and test how well it transfers to other species.

## Getting started

Interns create a private copy of this repository with "Use this template" on GitHub, then work in that copy.
